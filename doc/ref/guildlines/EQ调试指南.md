# EQ 调试指南

## 默认频段配置

### Pre-EQ（5段）— 保护性/修正性均衡，位于 DRC 之前

| 频段 | 默认类型 | 默认中心频率 | 默认 Q 值 | 用途 |
|------|---------|------------|----------|------|
| 1 | 高通 (HPF) | 30 Hz | 0.707 | 次声波滤波器 — 滤除极低频能量，防止 DRC 误触发 |
| 2 | 峰形 (Peaking) | 100 Hz | 1.0 | 低频修正 — 控制房间共鸣或补偿低频不足 |
| 3 | 峰形 (Peaking) | 500 Hz | 1.0 | 中低频 — 调整浑浊度/饱满度 |
| 4 | 峰形 (Peaking) | 2 kHz | 1.0 | 临场感 — 人声清晰度、刺耳感控制 |
| 5 | 峰形 (Peaking) | 8 kHz | 1.0 | 高频 — 齿音、空气感 |

### Post-EQ（5段）— 创意性音色塑造，位于 DRC 之后

| 频段 | 默认类型 | 默认中心频率 | 默认 Q 值 | 用途 |
|------|---------|------------|----------|------|
| 1 | 低频搁架 (Low-shelf) | 150 Hz | 0.707 | 低频倾斜 — 温暖或清瘦 |
| 2 | 峰形 (Peaking) | 400 Hz | 1.0 | 饱满度 |
| 3 | 峰形 (Peaking) | 1 kHz | 1.0 | 中频聚焦 |
| 4 | 峰形 (Peaking) | 3 kHz | 1.0 | 临场感/冲击力 |
| 5 | 高频搁架 (High-shelf) | 8 kHz | 0.707 | 高频倾斜 — 明亮或柔和 |

### Output EQ（2段）— 扬声器/房间补偿

| 频段 | 默认类型 | 默认中心频率 | 默认 Q 值 | 用途 |
|------|---------|------------|----------|------|
| 1 | 低频搁架 (Low-shelf) | 200 Hz | 0.707 | 小扬声器低频延展补偿 |
| 2 | 高频搁架 (High-shelf) | 6 kHz | 0.707 | 房间/距离高频衰减补偿 |

## 参数调试指南

### Fc（中心频率 / 截止频率）

| 频段 | 频率范围 | 听感描述 | 调试建议 |
|------|---------|---------|---------|
| 亚低音 | 20–60 Hz | 震动感、压迫感 | 非专业系统建议用 HPF 切除，避免浪费功放功率 |
| 低音 | 60–250 Hz | 力度、温暖、轰鸣 | 过量会"浑浊"、不足会"单薄"；建议用搁架或宽 Q 峰形 |
| 中低音 | 250–500 Hz | 饱满度、厚度 | 过量会"闷"、不足会"空洞" |
| 中音 | 500–2k Hz | 人声主体、乐器基频 | 人声最敏感区域；过量的 1k 区域会"鼻音重" |
| 中高音 | 2k–8k Hz | 清晰度、临场感 | 2-4k 增强提高清晰度，过量使人疲劳；6-8k 控制齿音和空气感 |
| 高音 | 8k–20k Hz | 空气感、泛音 | 搁架式滤波器适合作整体高频倾斜调整 |

### Gain（增益）

| 场景 | 建议范围 | 说明 |
|------|---------|------|
| 轻微修正 | ±3 dB | 修正录制缺陷或房间问题 |
| 明显音色调整 | ±6 dB | 明显的音色风格变化 |
| 极端修正 | ±12 dB | 仅在问题严重时使用；注意避免后续 DRC 过压 |
| 高通/低通 | 0 dB | 增益固定为 0（仅影响截止频率以下的衰减斜率） |

**调试原则：**
- Pre-EQ 增益不宜过大 — 增益会被 DRC 放大感知
- 削减优于提升 — 削减 3 dB 比提升 3 dB 更不易引入新的问题
- 提升低频前务必确认扬声器能承受 — 过量低频会损坏小扬声器

### Q 值

| Q 值 | 带宽（在 48k 下近似） | 听感 | 适用场景 |
|------|---------------------|------|---------|
| 0.5 | 宽（约 2.5 个八度） | 平滑、不知不觉 | 整体音色倾斜、房间修正 |
| 0.7 | 中等宽（约 1.4 个八度）| 自然 | 搁架滤波器默认值、一般性修正 |
| 1.0 | 中等（约 1 个八度）| 可察觉 | 单频段明显调整 |
| 2.0 | 窄（约 0.5 个八度）| 明显 | 定位特定问题频率、陷波 |
| 4.0+ | 极窄 | 极明显、可能产生铃声感 | 精确陷波、噪声消除 |

**调试原则：**
- 查找问题时先用窄 Q（4.0+）定位，再用宽 Q（0.7–1.0）修正
- 搁架滤波器推荐 Q=0.707（Butterworth 特性，过渡带最平坦）
- Q 越高，滤波器相位失真越大 — 仅在必要时用高 Q

### 滤波器类型选择

| 类型 | 何时使用 |
|------|---------|
| HPF | 切除次声波/直流分量；保护小型扬声器 |
| LPF | 极少用 — 仅用于特殊效果或带宽限制 |
| Peaking | 对特定频率范围施加增减 — 最常用的 EQ 类型 |
| Low-shelf | 对某频率以下的所有内容统一增减 — 整体低频/高频倾斜 |
| High-shelf | 对某频率以上的所有内容统一增减 — 整体亮度调整 |

## 调试工作流

### 步骤 1：识别问题

- 用粉红噪声 + RTA（实时分析）找到频率响应中的峰/谷
- 或用正弦波扫频，听哪些频率异常突出或缺失

### 步骤 2：定位具体频率

- 选择一个峰形滤波器，设置窄 Q（4.0）
- 设置较大增益（+10 dB 使异常频率更明显，或 -10 dB 确认是要削减的频率）
- 扫动 Fc 直到问题频率被准确定位

### 步骤 3：修正

- 降低增益到合理范围（±3–6 dB）
- 扩宽 Q 值使修正更自然
- A/B 对比开关该频段确认效果

### 步骤 4：验证级联效果

- 12 段 biquad 级联后，确认总频率响应符合预期
- 检查是否有意外的共振峰（相邻频段可能相互叠加）
- 用扫频信号验证幅度响应平坦度

## 常见问题

| 症状 | 可能原因 | 解决方法 |
|------|---------|---------|
| 级联后输出过大/削波 | 多个频段在同一频率提升叠加 | 检查各频段频率响应重叠；降低增益 |
| 声音"空洞" | 中低频（200-500 Hz）补偿不足 | 提升 Pre-EQ 或 Post-EQ 的 400 Hz 区域 |
| 人声不够清晰 | 2-4 kHz 区域不足 | 提升 Pre-EQ 2 kHz 频段 |
| 齿音过重 | 6-10 kHz 过突出 | 用窄 Q 峰形削减 6-8 kHz 附近 |
| DRC 被低频误触发 | 次声波/极低频能量过高 | 开启 Pre-EQ 第 1 段 HPF（30 Hz），确认生效 |
| 声音"闷"或"薄" | 搁架滤波器设置不当 | 检查 Post-EQ 的搁架增益和频率设置 |

## 参考文献

### 滤波器系数设计

- [rbj_cookbook.html](rbj_cookbook.html) — Robert Bristow-Johnson, *"Cookbook formulae for audio equalizer biquad filter coefficients"*。本文档中所有双二阶滤波器系数均基于此 Cookbook 公式计算。涵盖了 LPF、HPF、Peaking、Low-shelf、High-shelf 共 5 种滤波器类型的完整传递函数推导和系数设计方法。

### 频段划分与调音参考

- [ref_izotope_parametric_eq.html](ref_izotope_parametric_eq.html) — iZotope, *"Parametric EQ: What It Is and How to Use One"*。本文档中的频段划分、Q 值选择策略、以及各频段的感知描述参考了此文。iZotope 将可听频谱分为 7 个核心频段（Sub-Bass 至 Brilliance），并提供了各频段的增益调整建议和"减法优先"原则。
- Bobby Owsinski, *"The Mixing Engineer's Handbook"*（间接引用，经 iZotope 文章转述）。7 频段划分框架和"5 条 EQ 黄金法则"的来源：
  1. 声音浑浊 → 削减 250 Hz 附近
  2. 声音"鼻音"重 → 削减 500 Hz 附近
  3. 想要声音更好 → 削减
  4. 想要声音不同 → 提升
  5. 无法提升不存在的频率 — 先削减再提升

### 等响度补偿

- [ref_smc2019_loudness.pdf](ref_smc2019_loudness.pdf) — L. Fierro, J. Rämö & V. Välimäki, *"Adaptive Loudness Compensation in Music Listening"*, SMC 2019。本文档中等响度补偿（Loudness Compensation）的搁架滤波器设计参考了此论文。关键参数：一阶低搁架滤波器，转折频率 122 Hz，增益偏置 +0.485 dB，增益随听音响度动态调整。
- ISO 226:2003, *"Acoustics — Normal equal-loudness-level contours"*。Fletcher-Munson 曲线的现代标准化版本。等响度补偿的目标曲线由此标准定义。

### 硬件参考架构

- [ALC1320 Datasheet_V0.18.pdf](ALC1320 Datasheet_V0.18.pdf) — Realtek Semiconductor, *"ALC1320-CG/CGT 10W Stereo I2S/SoundWire Input Digital Audio Amplifier with Gen. III Speaker Protection"*, Rev. 0.18, 2024-02-19。本文档中的三阶段 EQ 架构（Pre-EQ 5 段 + Post-EQ 5 段 + Output EQ 2 段）参考了 ALC1320 的 µDSP 音频引擎设计。

### DSP 实现

- [NatureDSP_Signal_Library_Reference_HiFi3_3z.pdf](NatureDSP_Signal_Library_Reference_HiFi3_3z.pdf) — Cadence Design Systems, *"NatureDSP Signal Library for HiFi 3/HiFi 3z DSP"*, Library Release 5.0.0, API Revision 4.00, Mar 2025。HiFi3z 定点移植时使用的双二阶滤波器函数 `bqriir32x32_df1`（定点）和 `bqriirf_df1`（浮点）均来自此库。
